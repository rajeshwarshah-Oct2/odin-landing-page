# Tokyo Landing Page

A responsive **Tokyo-themed landing page** built with **HTML and CSS** as part of my frontend development practice.

This project focuses on creating a complete landing page layout using **Flexbox, responsive design, images, typography, spacing, buttons, and multiple page sections**.

## Built With

* HTML5
* CSS3
* Flexbox
* CSS Media Queries
* Google Fonts

## Features

* Tokyo-themed landing page
* Header and navigation section
* Hero section with Tokyo imagery
* Responsive navigation
* Responsive hero layout
* Tokyo highlights section
* Image-based information cards
* Quote section with `<blockquote>` and `<cite>`
* Call-to-action section
* Footer
* Flexbox-based layouts
* Responsive design for desktop, tablet, and mobile screens
* Responsive typography and spacing
* Image cropping using `object-fit`

## Responsive Design

The landing page is designed to adapt to different screen sizes using CSS media queries.

Responsive breakpoints currently include:

* **900px** — Adjustments for smaller desktop/tablet screens
* **700px** — Mobile layout changes and stacked hero section
* **450px** — Additional adjustments for smaller mobile screens

The hero section changes from a horizontal layout to a vertical layout on smaller screens, while typography, navigation, images, cards, and CTA sections are adjusted to fit smaller displays.
