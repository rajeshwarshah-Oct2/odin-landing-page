# Landing Page

A landing page built with **HTML and CSS** as part of my frontend development practice.

This project focuses on building a clean page layout using **Flexbox**, spacing, typography, buttons, and different page sections.

## Built With

* HTML5
* CSS3
* Flexbox

## Features

* Header/navigation section
* Hero section
* Information cards
* Quote section
* Call-to-action section
* Footer
* Flexbox-based layouts

## Responsive Design

The current version is designed for **desktop screens**.

Responsive/mobile styling has **not been added yet** and will be implemented in a future update.

## Project Status

**Desktop version: Complete**

**Mobile responsiveness: Not implemented yet**

## What I Practiced

* CSS Flexbox
* `justify-content` and `align-items`
* `gap`
* `flex-wrap`
* `min-height` and viewport units
* CSS spacing and sizing
* Basic page structure and layout
